🎓 การเรียนรู้ Git และ GitHub

โปรเจกต์นี้สร้างขึ้นเพื่อการเรียนรู้การใช้งาน Git และ GitHub

📚 Git พื้นฐาน

คำสั่ง Git ที่สำคัญ

  • git init - สร้าง Git repository ใหม่
  • git add . - เพิ่มไฟล์ทั้งหมดเข้า staging area
  • git commit -m "ข้อความ" - บันทึกการเปลี่ยนแปลง
  • git status - ดูสถานะของ repository
  • git log - ดูประวัติการ commit

🌐 GitHub พื้นฐาน

การใช้งาน GitHub

  • สร้าง repository บน GitHub
  • เชื่อมต่อ local repository กับ GitHub
  • Push โค้ดขึ้น GitHub
  • การทำงานร่วมกันกับผู้อื่น

🛠️ ฝึกปฏิบัติ

ลองทำตามขั้นตอนนี้

  1. แก้ไขไฟล์นี้ (เพิ่มข้อความใหม่)
  2. ใช้คำสั่ง git add .
  3. ใช้คำสั่ง git commit -m "อธิบายการเปลี่ยนแปลง"
  4. ใช้คำสั่ง git log เพื่อดูประวัติ

สร้างขึ้นเพื่อการเรียนรู้ Git และ GitHub
